One absurd clause, at most 200 characters, hidden in a terms-of-service agreement — written by `main.ts` to `/output/entry.txt`. The program assembles the clause from its opener, grant, and escalation, then checks it is a single line of 1–200 characters before writing it.

Entry for the [The Absurd Clause Contest](https://make.fun/bounty/u-donrulezz-the-absurd-clause-contest-035cc0f1) competition on make.fun.
